- **The `codeden-tools` skill lists each role's own tools.** When a provider's company policy blocks MCP and CodeDen hands its tools over as a skill instead, the skill now documents exactly the tools the session's role is offered, from the same registry the MCP endpoint serves. A PM or orchestrator on Copilot no longer gets a skill pointing at an agent's tools (`finish`, `create_pull_request`, the browser) while its real ones (`start_session`, `get_project_status`, `get_overview`, `message_pm`, …) are missing.
