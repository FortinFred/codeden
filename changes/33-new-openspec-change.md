- **New change for an OpenSpec work source.** A project whose factory takes its work from `openspec/changes/` gets a **New change** button beside the factory controls: a title and a body (why and what) write `openspec/changes/<slug>/proposal.md`, and the next factory check takes it in. The slug keeps only lowercase letters, digits and hyphens, an existing folder is never overwritten, and the change is written in the project's main checkout.
