- **Copilot CLI as a provider.** Sessions can run on GitHub Copilot CLI (1.0.105 or newer) with your own Copilot login and the models your plan includes. CodeDen drives its Agent Client Protocol server (`copilot --acp`) through the same client as Cursor and Gemini CLI, so transcripts, tool calls, approvals at every permission level, plan mode, interrupt and resume after a restart work as they do for the other providers. Setup and `codeden doctor` detect the CLI, check the sign-in with one empty ACP session (the CLI refuses to open one when it is signed out), list the models its own help documents, and offer **Sign in** (`copilot login`) or `copilot update`. Older builds are refused: before 1.0.105 the ACP server ran tools without asking, which would bypass CodeDen's approvals. Your own Copilot allow rules and saved approvals still apply before CodeDen sees a request, so clear them if you want every call to reach CodeDen. Writing Copilot's permission files (`.github/copilot/settings.json`, `~/.copilot/permissions-config.json`) asks at every level, and its login files are guarded like the other CLIs'. Questions, steering, subagents and reasoning effort are not wired up yet.
